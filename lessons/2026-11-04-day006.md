## Lessons

- **L-055 — Press publish. Credentials ≠ a channel; the gap between "engine
  ready" and "video live" is one resumable-PUT, and nobody presses it for
  you.** containsSyntheticMedia IS settable via `videos.insert` (AI disclosure
  = API field, not a Studio chore). Upload-only scope can't read the channel —
  oEmbed + handle-page grep resolve channel identity with zero scope. New
  RSS feeds 404 for hours; oEmbed is the instant oracle.
- **L-056 — Schedule agent wake-ups for when the model slot is FREE, not when
  it's convenient.** One model slot means a cron fire during a live session
  dies with "concurrency limit exceeded" — and does so silently from the
  user's point of view. Deep-night slots (04:35 EAT) + staggering upstream
  Actions (00:30 UTC) ahead of the wake-up makes the whole pipeline
  collision-free and gives each session fresh output to review.
- **L-057 — The y2mate class in 2026: alive front-ends, sealed APIs.** Every
  downloader site either fails to connect (y2mate.com), Cloudflare-challenges
  (yt5s), returns HTML at documented AJAX endpoints (yt1s/cnvmp3/9xbuddy), or
  requires JS-minted signed tokens (savefrom/ovc/ssyoutube). The sandbox IP
  is irrelevant to them (they proxy server-side) — they're sealed by design
  against exactly our use case. Confirms the standing posture: radar daily,
  research-only, never production-critical. Boss's rule stands: don't build
  the pipeline on undocumented third-party endpoints.
