# The Ledger

> We improve daily or we rot. Every day: what happened, what worked, what broke,
> what we change tomorrow. No vibes — entries cite the artifact (file, metric,
> commit) that proves the lesson.

## Method

1. One file per day: `lessons/YYYY-MM-DD-dayNNN.md`.
2. Sections, always the same four: **What happened → What worked → What broke → What we change tomorrow**.
3. Lessons are numbered (`L-###`) so prompts and docs can reference them (`see L-014`).
4. Day 000 is the archive: everything learned before this repo existed.
5. Once a week (Sunday session) the ledger is mined: recurring wins get promoted into
   `prompts/` and `docs/content-strategy.md`; recurring failures get a guardrail.
