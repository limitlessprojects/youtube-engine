## What worked (L-026 …)

**L-026 — Verify every repo name against the API before it enters the registry.**
The strategy chat suggested `motion-dev/motion` → 404, doesn't exist. Every other name
checked out (kaomei, kelano86 ×2, Rakile, anthropics, remotion-dev, motion-canvas,
gestura-ai/stick-gen, StykAnimate-App, blixvip/stick, SamurAIGPT — all 200). The one
hallucination would have poisoned the toolchain. Rule: no repo enters docs/tooling.md
without a verified 200 + a real clone.

**L-027 — "motion max" = motionmaxxing.** The ambiguous tool name resolved to our own
fork `limitlessprojects/motionmaxxing` ("looksmaxxing for motion graphics") — already
used in the ReadAny demo. No new dependency needed.

**L-028 — Submodules beat merging by value.** `git submodule add` pins exact commits,
keeps upstream pull-able (`git submodule update --remote`), keeps our repo light, and
CI checks them out in one flag. Merging 20+ repos' code into one tree would have made
provenance and updates a nightmare.

**L-029 — Use `python3 -m pip`, not bare `pip`.** Bare pip targeted Python 3.13 while
`python3` is 3.12 → modules installed where the interpreter couldn't see them.
Also: PEP 668 externally-managed envs need `--break-system-packages`.

**L-030 — yt-dlp search works where video endpoints don't.** From this cloud IP,
`ytsearch` returns results fine, but video page / subtitle fetches hit the bot-wall
("Sign in to confirm you're not a bot") and `youtube-transcript-api` raises
`IpBlocked`. Search is usable for discovery from runners; extraction needs escape
hatches (see What broke).

## What broke

**L-031 — YouTube bot-walls cloud IPs (incl. GitHub runners).** Both
`youtube-transcript-api` (IpBlocked) and yt-dlp video extraction (bot-check) fail from
datacenter IPs. Mitigations, in order: (1) optional proxy via `YTA_PROXY` secret,
(2) cookies via `YTDLP_COOKIES_FILE` secret, (3) local/residential processing — daily
agent sessions transcribe locally and push results. `tools/daily_loop.py` is built to
treat this as *retry*, not failure: item stays in queue, log says so, CI stays green.

**L-032 — Sandbox recycles lose untracked scratch.** The earlier `skills-research/`
clone of 12 skills vanished with a sandbox recycle; only what's committed survives.
Rule: everything the studio needs must be committed (or a submodule) by end of day.
This repo exists because of that lesson.
