## What worked

- **L-068 — Fail loudly, then read the log: the bug announces itself.** Adding
  "log status + body head, fail on shortfall" to the workflow turned a silent
  0/8-with-green-check into an instant diagnosis: `HTTP 200 but not MP3
  (87352B head=b'\xff\xfb...')`. The audio was never broken — the verifier was.
- **L-069 — Validate media by decoding, not by magic-number prefix.** MP3s
  legitimately start with either an ID3 tag OR a raw MPEG frame sync
  (0xFFEx/0xFFFx). A prefix check that admits one valid encoding rejects the
  other. (Decode with ffprobe if you need certainty.)
- **L-070 — The gate must know the intent it's gating.** Hardcoded per-scene
  notes from #0002 made the verifier flag #0003's frames against #0002's
  design ("no birds in the sky!", "remove the character that should not
  exist"). Notes now live in each short's `gate/notes.json`; the lesson
  generalizes: verifiers carry their spec with the artifact, not in a global.
- **L-071 — Rig angles are measured from straight DOWN.** `a:158, b:-120`
  puts the forearm at a2=38° (pointing down) — arms-up poses need small |b|
  (a2 ≈ 150°). Read the joint math (`V2.joints`: direction = sin(a), cos(a))
  before tuning poses by guesswork.
- **Pixel probes settled 3 of 5 disputes in one run** (day-008's L-064 paying
  off): caption "collisions" in s1/s2 were the caption's own words in the
  hero's x-column. Two claims survived arbitration and were real (missing
  hero, shoe-text contact) — probes sort real from phantom in minutes.
- Pacing measured per-script, not assumed: the same voice at the same rate
  ran 238 WPM on this script vs 207 on #0002's — text-dependent speed is
  real. VO_RATE env override now exists; match the band per script.

## Lessons

- **L-068** Fail loudly, then read the log — silent failure paths turn
  diagnostics into archaeology; one print of the HTTP status + body head
  located the bug instantly.
- **L-069** Validate media by decoding, not by magic prefix — MP3 frame sync
  vs ID3 tag; verifiers must accept every valid encoding of the thing they
  verify.
- **L-070** Verifiers carry their spec with the artifact — per-short
  gate/notes.json; a global note table guarantees cross-contamination as
  soon as a second artifact exists.
- **L-071** Read the rig's joint math before tuning poses by eye — a=from
  down, a2=a+b is the forearm's absolute angle.
