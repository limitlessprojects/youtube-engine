## What worked

- **L-042 — The gap was the world, not the character.** The single biggest quality
  jump came from building the SET (street + lamp light + LightVeil + dust + foreground
  blur) and the LIGHT (rim + glow + grain), not from redrawing the stickman. Spend the
  next visual iteration budget on world density and light before character detail.
- **L-043 — Deterministic frames make renders resumable.** Every frame is a pure
  function of t, so `--resume` (skip frames already on disk) is always safe. Added to
  `tools/render_short.py`; saved ~10 min on the 1,226-frame rebuild.
- **L-044 — Atomic pushes bound the blast radius of context loss.** Only unpushed work
  was lost (engine v2 + scene rewrite); everything through day 003 survived on GitHub.
  Rebuilding 7 files from session context took minutes because the craft was documented
  (docs/visual-craft.md) and the code was in-context. Push after every milestone.
- **L-045 — Gate the animation, not the still.** The VLM inspector repeatedly flagged
  (a) count-up readouts at intermediate values, (b) decks "floating" in space scenes,
  (c) night crescents it couldn't see. Checklist now explicitly says count-ups may show
  intermediate values; space characters stand on decks *by design*. Eye arbitration of
  bbox-flagged frames stays mandatory before any code change.

## What broke

- Sandbox recycle → repo dir `root:root 700`, unrecoverable as user `z`. Fix flow:
  `mv` it aside (parent is writable) → fresh clone → rebuild from context. Quarantined
  copy left at `/home/z/my-project/youtube-engine.ro` until the next recycle.
- `re.sub()` interprets `\n` escapes in the *replacement* string: patching
  `tools/vlm_gate.py`'s NOTES dict injected raw newlines → SyntaxError. Fix: build the
  replacement with plain string joins (no regex replacement escapes).
- Transcript mirrors are per-video, not per-service: tactiq + youtubetotranscript both
  dead for `9tbxDgcv74c` while the services work for others. A blocked video can stay
  blocked forever — rotate the queue instead of retrying the same head-of-line item.
- VLM inspector parse flakes ("🚀 Initializing Z-AI SDK…" inside JSON output) — the
  3-attempt retry in `vlm_gate.py` handles most, but re-run `--scene <sid>` when it lands.
