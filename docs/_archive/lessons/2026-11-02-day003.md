## What worked

- ASR round-trip as free, deterministic VO QC — zero-cost confidence that the
  TTS matched the script before any render time was spent.
- VLM gate + fix loop within the N=2 cap: every round's flags got cheaper
  (13 -> 8 -> 1). Composition notes in the gate prompt (authoritative intent
  per scene) fixed the VLM's misreads of scene semantics.
- `measureText` for captions — never estimate font widths by hand.
- The proxy pool validated 3/240 in ~2 min with round-robin source sampling
  and http-only filtering (requests can't do socks5 without PySocks).

## What broke

- **L-039 — escalation short-circuit (L-033 pattern).** An exception from
  path-6's first sub-attempt aborted the whole escalation. Rule now in code:
  wrap each proxy attempt; a block anywhere is evidence about that attempt only.
- **L-040 — single-frame VLM gates can't judge animation.** It demanded the
  marble end-state at u25 of a 5.3s collapse. Rule: gate animations at
  end-state + one mid frame; treat mid-flight prop-state flags as informational.
- **L-041 — yt-dlp subprocess timeout must shrink in proxy mode** (180s x 3
  slow proxies blows a CI leg). Now 75s when PROXY_URL is set.
- finish_short.py's final loudness probe decoded the whole video and hung past
  10 min; probing `-map 0:a` only fixed it (report completed by hand once).
